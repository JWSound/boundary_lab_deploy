# Boundary Lab Deploy 0.1.0rc3

Unsigned desktop test candidate with CPU and NVIDIA CUDA solver selection.

- Open Preferences from the top-right button to select the solver backend.
- On first launch, select CUDA if the engine detects it is functional; otherwise
  select CPU. Save later user selections across application restarts.
- Support boundary and coupled speaker-ROM solving on either backend, including
  cached field evaluation and frequency sweeps.
- Invalidate cached application results when switching backends.

This candidate requires BEAT Engine 0.3.0. Final published wheel pins and exact
installer qualification results must be recorded before distribution.
Signing is not configured; Windows will identify the installer as unsigned.
