# Boundary Lab Deploy 0.1.0rc4

Unsigned desktop candidate with persistent CPU/CUDA preferences and BEAT 0.3.0.
On first launch, use CUDA when available and otherwise CPU.

Fix Windows shutdown during solver detection or solving: terminate the Python
worker and its Julia descendants together. The rc3 packaged launch test exposed
an orphaned Julia probe, so rc3 must not be promoted for distribution.

Both engine pins retain the qualified BEAT 0.3.0 wheel SHA-256
`b1476287d893a208d14f6c5ef2292e7a831c78d903d72357a5a29a291016fdae`.
Numerical behavior is unchanged from rc3. Final artifact hashes and qualification
results accompany the installer. Signing is not configured.
