# Boundary Lab Deploy 0.1.0rc2

Unsigned desktop test candidate. Fix GPU-less build hosts silently omitting CUDA
artifacts: register and pin both runtime and compiler preferences before Julia
artifact selection. Fail the build if essential CUDA DLLs or ptxas are absent.
The earlier rc1 app-launch check passed but its bundle inventory failed CUDA
qualification; it must not be promoted to a stable release.

A signed release still requires configured signing credentials and qualification
of the exact final installer. No stable desktop release is published here.
