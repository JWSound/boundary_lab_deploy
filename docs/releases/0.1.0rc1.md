# Boundary Lab Deploy 0.1.0rc1

Initial standalone Windows desktop distribution, independent of Boundary Lab.

- Bundled Python, Julia and a pinned BEAT Engine release.
- Mixed-package coupled solves and optional OBJ speaker viewport models.
- Per-user runtime data and an offline-capable solver bundle.

Unsigned candidates are test artifacts only. The signed release workflow requires
configured Windows signing credentials. First solver startup can take several
minutes while Julia compiles its user cache. A maintainer must qualify a real
coupled CUDA solve using the final installer before publishing a stable release.
